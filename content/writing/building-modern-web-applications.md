## Start with constraints

Start with the limits of a project: deployment, maintenance, and the tasks visitors need to complete.

## Performance is a product feature

Use responsive images, avoid unnecessary dependencies, and make the first useful screen available quickly.

## Design for maintenance

Keep content separate from presentation and document decisions that are hard to infer from code.
